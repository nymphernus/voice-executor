## Модули

### audio.py
- Проверка доступности микрофона
- Создание аудиопотока PyAudio
- Список устройств ввода

### recognizer.py
- Загрузка модели Vosk
- Непрерывное распознавание речи
- Колбэки для final и partial results

### nlu.py
- Нормализация текста (ё→е, нижний регистр)
- Сопоставление с триггерами
- Fuzzy matching (расстояние Левенштейна)
- Антидребезг

### executor.py
- Реестр действий
- Выполнение по имени
- Обработка неизвестных команд

### commands/
- system.py — системные команды (exit, F5)
- browser.py — браузер (YouTube)
- apps.py — приложения (Dota 2, PHPStorm)
- discord.py — Discord (Alt+F2)

### config.py
- Загрузка TOML
- Dataclass-конфигурация
- Переопределение через env vars

### model_manager.py
- Проверка наличия модели
- Скачивание и распаковка

### logging_setup.py
- Консоль + файл с ротацией
- Уровни DEBUG/INFO/WARNING/ERROR

## Поток данных

1. **Запуск:** `main.py` → `app.py:main()`
2. **Инициализация:** загрузка конфига → логирование → модель → распознаватель
3. **Цикл:** аудио → Vosk → текст → NLU → команда → действие
4. **Завершение:** Ctrl+C или команда «стоп»
